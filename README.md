# 🎧 Spotify Music Trends & Popularity Dashboard

## 📊 Overview
An interactive Tableau dashboard analyzing Spotify data to identify music trends, popular artists, and genre insights.

## 🛠️ Tools
- Tableau  
- Excel / CSV  

## 📈 Key Insights
- Top artists and trending songs  
- Genre-wise popularity  
- Impact of features like energy & danceability
